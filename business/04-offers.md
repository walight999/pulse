# 💰 Pulse — Offers

## Pricing tiers

### Free — $0 forever

**Audience**: Individual prosumer using one machine.

**Features**:
- All v1.0 features (subscription tracker, Claude analytics, activity, ROI hero)
- Multi-currency (30+ via ECB live rates)
- Smart auto-detect (monthly/yearly/cancelled classification)
- Renewal alerts (Windows toast 3 days before)
- Cost spike alerts (3× average threshold)
- CSV export
- Local SQLite + backup rotation (7 daily)
- Browser extension capturing web AI sessions
- MIT licensed, full source on GitHub

**What's NOT in Free**:
- Cloud sync (cross-device)
- Mobile app
- Friend leaderboard
- Multi-user / team features
- "Ask Pulse" AI assistant

**Why give so much for free**:
- Build category leadership through ubiquity
- Local-first means zero marginal cost to us
- Free users become Pro upgrade pipeline when they buy second device or want mobile
- Open-source = enterprise can audit before considering Team tier

---

### Pro — $9/mo · $89/yr · $199 lifetime

**Audience**: Prosumer with multiple devices, wants mobile companion.

**Free features +**:
- Cloud sync (E2E encrypted, opt-in per data type)
- Mobile PWA (iOS/Android home screen install)
- Push notifications (renewals, spend spikes, weekly digest)
- Friend leaderboard (5 categories: Best ROI / Streak / Token wizard / Power day / Project depth)
- Multi-provider parsing live (OpenAI, Cursor, Gemini, Copilot, Perplexity)
- "Ask Pulse" AI assistant (natural-language queries)
- Receipt OCR (snap photo of receipt → auto-add subscription)
- Bank integration (Plaid US, KBank/SCB TH)
- Weekly email digest
- 30-day free trial (no card required)

**Why $9/mo**:
- Anchored against Linear ($8), Notion ($10), Bear ($1.49/mo)
- 1 average AI sub cancelled saves $20+ → Pulse pays for itself
- Annual saves 18%, lifetime is a one-time emotion-driven purchase

**Why annual + lifetime exist**:
- Annual ($89 = 18% off) captures committed users, reduces churn
- Lifetime ($199 = ~22 months upfront) is a launch-only special, drives high LTV upfront cash

### Team — $19/seat/mo · min 3 seats

**Audience**: 5–50 dev teams who pay collectively for Claude Code / API.

**Pro features +**:
- Shared team dashboard
- Per-user attribution (which dev burns most Opus?)
- Role-based access (admin / member / viewer)
- Slack / Teams / Discord integration (daily digest + spike alerts)
- CSV/PDF export with per-project tagging (for client billing)
- Centralized billing
- Admin policies (default plan, alert thresholds)
- Audit log access (security + compliance)

**Why $19/seat**:
- LiteLLM is free but requires DevOps (~2 days of work). Pulse Team saves that.
- 10-seat team = $190/mo = 1 dev's Claude burn for 2 weeks
- Compared to ClaudeMetrics $49 team / $199 enterprise — we're cheaper for 5-10 seats

**Why min 3 seats**:
- Discourages solo-dev "Pro instead of Team" arbitrage
- Forces real team usage = real word-of-mouth
- Team-of-1 = use Pro tier (cheaper for them, healthier signal for us)

---

### Enterprise — $199/seat/mo · custom contracts

**Audience**: 50+ employee orgs that need SSO + compliance.

**Team features +**:
- SSO/SAML 2.0 + OIDC (Okta, Azure AD, Google Workspace)
- SOC 2 Type II compliance
- Custom roles + permission groups
- Dedicated success manager
- 99.9% uptime SLA
- Custom data residency (EU, Asia)
- Audit log retention 7 years
- Custom integrations (HRIS for headcount changes, billing exports to NetSuite)
- Pulse SDK / API access (programmatic data access for internal tools)
- White-label option (optional)

**Why $199/seat**:
- Comparable to Datadog ($31-$59), Notion Enterprise ($25), Linear Business ($14)
- Enterprise procurement understands $200/seat as "premium tool"
- Volume discount kicks in at 50+ seats (~30% off list)

**Why this tier requires sales conversation**:
- Contracts, SLAs, custom procurement
- Compliance docs (SOC 2 report, security questionnaire)
- 30-60 day buying cycle
- Not self-serve
